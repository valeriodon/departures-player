# Departures · TV player

A tiny player for the **Departures** split-flap board templates made in [SVGator](https://www.svgator.com) for the #svgatorchallenge.

SVGator exports carry no audio, so this page adds the alert sound: it listens to the board through the SVGator Player API and plays a sound each time the board flips.

- Pick a board: Aurora Café (list), Studio Nine (schedule), Barber Seven (queue), Sea House (welcome)
- Pick the alert: soft bell, ding-dong, shop bell, chime, wood block, your own file, or none
- Volume, and every update or the first update only
- Full screen with F, settings with S

Open it on the screen behind the counter: https://valeriodon.github.io/departures-player/

Boards and sounds by Valerio Donfrancesco. All artwork is original; fonts are open source (Chivo Mono, Bricolage Grotesque, Geist).
